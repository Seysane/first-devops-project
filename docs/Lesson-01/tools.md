Installed Tools:

git – A version control system and an absolute foundation for DevOps,
used for tracking code changes and collaborating with other developers.

curl – A  tool for transferring data to or from a server using various
protocols (HTTP/HTTPS) frequently used for downloading files or testing APIs.

wget – A utility for retrieving content and files from the web,
unlike curl, it focuses primarily on downloading files and supports resuming interrupted tranfers.

unzip – A simple tool for extracting archives in .zip format directly
from the terminal.

htop – An interactive process viewer, it allows you to monitor 
CPU usage, RAM, and manage running programs in real-time.

tree – A utility that displays the directory and file structure in a 
readable “tree” format within the terminal.

jq – A lightweight and flexible command-line JSON processor. It is used 
to slice, filter, and transform structured data, making it indispensable
for handling API responses and configuration files.
