### Multi Container Application

Exercise requirements:

- download `Nginx` and `postgresql` images
- run both containers with settings:

`Nginx` port 8080:80

`PostgreSQL` port `5432:5432` with POSTGRES_PASSWORD=

- modify `index.html` with `docker exec`
- check both container logs

#### Modify the index.html site with docker exec


To modify the base index.html welcome message I used:


to enter:
```bash
docker exec -it nginx-server bash
```

to replace index.html base site:
```bash
echo "<h1>Docker Multi Container Application - Sane</h1>" > /usr/share/nginx/html/index.html
```

to exit:
```bash
exit
```
